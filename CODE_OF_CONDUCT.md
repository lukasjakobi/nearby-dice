# Code of conduct

Nearby Dice follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, reviews and every other project space.

## Reporting

Report unacceptable behaviour to the maintainer at lukas@jakobi.io. Every report is reviewed and
kept confidential. The maintainer decides on consequences as described in the Covenant's
enforcement guidelines.
